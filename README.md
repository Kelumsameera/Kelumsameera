## About me

I work across **industrial automation, IoT and full-stack web development**. My projects connect physical equipment and operational workflows with APIs, databases, dashboards and practical user interfaces.

- **Industrial systems:** ESP32, Modbus TCP/RTU, sensor and equipment monitoring, real-time dashboards
- **Web applications:** Next.js, React, TypeScript, Node.js, Express, Python / FastAPI
- **Data & deployment:** MongoDB, PostgreSQL, Firebase, Docker, Linux, Vercel and self-hosted services
- **Focus:** Maintainable code, secure APIs, reliable deployments and useful engineering tools
